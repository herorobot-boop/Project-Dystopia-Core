Phase C: 肉体の鋳造（Incubation）
python core/train_lora.py 高スコアな画像からLoRAを自動生成する。AIは君の理想を「画風」として学習する。

Phase D: 時間の超越（Motion）
python core/run_video_batch.py 進化した思想を動画へと昇華させる。
