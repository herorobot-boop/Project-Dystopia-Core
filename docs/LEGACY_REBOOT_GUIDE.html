👁️ PROJECT DYSTOPIA: THE LEGACY REBOOT GUIDE

Edition: v1.1.0 | Executor: Herorobot

⚠️ 注意: RunPodはセッション終了時に /workspace 以外をすべて忘れます。このガイドに従い、速やかに記憶（データ）をサルベージしてください。

🧭 第1章：要塞の再建 (Environment)

STEP 1: GitHubから脳を復元

git clone https://github.com/Herorobot/Project-Dystopia-Core.git
cd Project-Dystopia-Core
git config --global user.name "Herorobot"
git config --global user.email "one.hero.robot.eno@gmail.com"

STEP 2: 神経系の修復（ライブラリ導入）

pip install -r requirements.txt

📦 第2章：魂のサルベージ (Data Restore)

rclone config設定後、以下の儀式を行え。

# 記憶の復元
rclone copy gdrive:Dystopia_Full_Backup/outputs ./outputs --progress
rclone copy gdrive:Dystopia_Full_Backup/lora_outputs ./lora_outputs --progress

🔄 第3章：創造のサイクル (Operation Loop)

  • 思想生成: python core/run_batch.py
  • 審美眼（画像）: python core/score_thoughts_gui.py
  • 思想進化: python core/evaluator.py
  • 肉体化（LoRA）: python core/train_lora.py
  • 時間化（動画）: python core/run_video_batch.py
  • 審美眼（動画）: python core/score_videos_gui.py

☁️ 第4章：記憶の逃走路 (Backup)

作業終了時には必ず魂をクラウドへ逃がせ。これを怠ればすべては無に帰る。

bash sync_to_gdrive.sh
